## Ручная проверка и ограничения среды

Цепочка **физическое касание → sample → сервер → статистика не подтверждена**.
Открытие sample через native UI automation зависало до прерывания. Диагностический
запуск бинарника не упал за 12 секунд и был остановлен timeout; в stderr было только
системное UIKit-сообщение. Это не доказательство отображения UI или доставки ввода.
Полная матрица: [manual-checks.md](manual-checks.md).

- Android/iOS устройства и симуляторы не проверялись; библиотечная сборка не заменяет запуск.
- Sample собран на Mac Catalyst; его Android/iOS/Windows сборки отдельно не проверены.
- Windows runtime и нативная PRI/pack-сборка не проверены. На Mac MakePri.exe не исполняется.
  Отключение PRI позволило проверить C#, но локальный Windows pack закономерно остановился
  NU5026 из-за отсутствия RTelemetry.Maui.pri. Никакой фиктивный PRI не создавался.
- Локальный RTelemetry.Maui nupkg содержит Android/iOS/Mac Catalyst. CI собирает Windows
  на Windows runner и объединяет его артефакты с Mac-пакетом. Объединение проверено
  синтетическими архивами; полный workflow с настоящими Windows-артефактами ещё не запускался.
- Docker CLI отсутствует; Dockerfile/compose не запускались. Деплой HTTPS/systemd/nginx
  не выполнялся; docs/server.md содержит примеры конфигурации.
- Визуальное отображение Razor-страницы в браузере не проверено вручную; HTML/SVG/CSV
  и фильтры подтверждены интеграционными тестами.

## Важные правила эксплуатации

Отзыв согласия стирает очередь и отменяет текущую доставку; уже принятый сервером запрос
не отменяется задним числом. Для удаления данных используется отдельный админ-эндпоинт.
Короткий фон сохраняет sessionId; session.end пишется на каждый фон с накопительной
длительностью (не суммировать). Новая сессия начинается после SessionTimeout.
JSON Lines — провайдер одного процесса разработки **без дедупликации**; production — Postgres.
Фильтр страницы карты не сужает общий CSV; карта показывает первые 5000 точек.
Свыше 100000 событий нужно сузить фильтры — экспорт не обрезается незаметно.

## Открытые вопросы перед реальным сбором и публикацией

- Выполнить ручную матрицу на целевых устройствах: Popup, модальные страницы, списки,
  изменения геометрии, мультитач, синхронная навигация и UIScene/несколько окон.
- Невидимый элемент без layout geometry нельзя геометрически распознать как disabled_target;
  непрямоугольный Clip/сложная трансформация оцениваются ограничивающим прямоугольником.
  Toolkit Popup v1 требует отдельной проверки; sample использует v2 (15.0.1).
- Согласовать политику согласия/несовершеннолетних и профиль событий TBG (privacy.md/events.md).
- Выполнить native Windows CI/pack и все jobs до публикации через v1.0.0-rc.1.
- Настроить NUGET_API_KEY и environment nuget, настоящие серверные секреты, HTTPS,
  доверенные proxy IP, бэкапы и срок удаления из бэкапов.
