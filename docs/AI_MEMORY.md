# Память проекта для ИИ

> Для кого: ИИ-ассистенты и разработчики. Читать целиком перед задачей в репозитории.

## 1. Проект

RTelemetry — универсальная телеметрия RelaxerR Games: NuGet-пакеты клиента для C#-приложений
и собственный сервер с фронтом статистики. Первый потребитель — The Book Game (репозиторий
`TheBookGame`), данные идут в магистерскую ВКР (репозиторий `Thesis`, `docs/PROJECT_CONTEXT.md`,
раздел «Планируемые данные»). Задача-основание — TheBookGame#502.

## 3. Инварианты

- Клиент и сервер не знают предметную область. Игровые понятия (сцена, выбор) живут только
  в адаптере приложения и в `docs/events.md`.
- Без `ConsentState.Granted` события не пишутся ни в память, ни на диск. `Denied` стирает очередь.
- Никаких текстов, которые игрок читает или вводит, и персональных данных — только id, числа, флаги.
  `ClickTracker` не читает `Text` элементов.
- Каждое событие несёт `appVersion` и `contentVersion`.
- Клиент не бросает исключения в хост после конструктора; проблемы — в `OnDiagnostic`.
- Изменение формата = `TelemetrySchema.CurrentVersion` + клиент + сервер + тест + `docs/events.md`
  в одном изменении. Сервер должен принимать все версии, которые ещё могут прислать живые клиенты.
- `RTelemetry.Contracts` и `RTelemetry.Client` не зависят от MAUI и ASP.NET.

## 4. Работа

- Язык документации и коммитов — русский; идентификаторы и XML-комментарии API — как в коде.
- Коммиты: `feat:`/`fix:`/`refactor:`/`test:`/`docs:`/`chore:` и краткий диагноз.
- Если сборка или тесты не подтверждены, явно указывать это в результате.
- Сборка без MAUI workload: `dotnet test tests/RTelemetry.Client.Tests`, `dotnet build src/RTelemetry.Server`.

## 5. Решения

Новое сверху. Формат: дата — решение — причина.

- 2026-10-07 — отдельный репозиторий с NuGet-пакетами, а не git submodule в игре: пакет даёт
  версию по SemVer и не требует `submodule update` в CI и облачных сессиях; на время активной
  разработки игра подключает проекты локально (`docs/integration.md`).
- 2026-10-07 — собираем каждый клик (`ui.click`, автоматически через `ClickTracker`) плюс
  смысловые события приложения: клики без контекста сцены и выбора не интерпретируются.
- 2026-10-07 — конверт общий: `name` + плоские `props` (строка ≤ 256, число, bool); имена
  `[a-z0-9._-]`, первая буква или цифра.
- 2026-10-07 — `installId` — случайный GUID клиента, не идентификатор устройства; сбрасывается
  `ResetInstallId()`.
- 2026-10-07 — сервер и фронт — одно ASP.NET Core-приложение (Minimal API + Razor Pages), фронт
  за HTTP Basic, без пароля выключен. Хранилище первой версии — JSON Lines по проекту и дню;
  следующий шаг — PostgreSQL с уникальностью по `Id` (`docs/server.md`).
- 2026-10-07 — все проекты пока только `net10.0` (как The Book Game); `netstandard2.0` для
  Contracts/Client — когда появится потребитель на другом рантайме (например, Unity).
