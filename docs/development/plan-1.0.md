# План выпуска 1.0.0-rc.1

Дата: 2026-10-07. Исходная точка: fc9afc0. Публикация и push запрещены задачей.

## Потоки и владение

| Поток | Ветка / worktree в ../RTelemetry-wt/ | Область |
|---|---|---|
| 0 | release/scaffold / scaffold | Первичная сборка, исправления исходного каркаса |
| 1 | release/input / input | Чистая модель ввода, MAUI платформы, sample, ручной чеклист |
| 2 | release/client / client | Надёжность клиента, сессии, хранилище, транспорт, тесты |
| 3 | release/server / server | PostgreSQL, API, статистика, интеграционные тесты, Docker |
| 4 | release/packages / packages | Метаданные пакетов, лицензия, CI, безопасность |
| 5 | release/docs / docs | Согласованная документация и итоговый отчёт |

## Порядок

1. Проверить исходную сборку и тесты; исправить блокирующие дефекты в потоке 0.
2. Параллельно делегировать потоки 1, 2 и 3 отдельным агентам в worktree.
   MAUI lifecycle принадлежит потоку 1, API сессий — потоку 2; согласовать интерфейсы.
3. Основной агент ведёт пакеты/CI в потоке 4, затем документацию в потоке 5.
4. Каждый поток делает небольшие русские коммиты и проверяет свою область.
5. До интеграции в main собрать совмещённые изменения в integration worktree,
   прогнать доступные сборки, тесты и pack. Только зелёные изменения интегрировать.
6. Зафиксировать фактически выполненные проверки, ограничения платформ и открытые
   вопросы. Не выдавать чеклист за выполненную проверку и не публиковать пакеты.

## Проверки

- dotnet build RTelemetry.slnx; dotnet test; отсутствие nullable warnings.
- Чистые xUnit тесты hit testing, drag/tap, мультитач и нормализации координат.
- Клиент: согласие, отзыв, гонки, повреждение файлов, HTTP статусы, retry, сессии.
- WebApplicationFactory с JSON Lines; PostgreSQL по переменной окружения.
- Release pack и содержимое nupkg; проверка исходников на секреты.
- MAUI и sample: сборка доступных платформ; запуск Mac Catalyst и локального сервера
  при доступной среде; Android/iOS и фактически недоступные проверки — ручной чеклист.
