# Участие в разработке

Сначала прочитайте `docs/AI_MEMORY.md` и карту документации в README.
Требуется .NET 10 SDK; для MAUI — соответствующий workload и платформенные SDK.

```sh
dotnet test tests/RTelemetry.Client.Tests
dotnet test tests/RTelemetry.Input.Tests
dotnet test tests/RTelemetry.Server.Tests
dotnet build RTelemetry.slnx
```

Документация и сообщения коммитов — на русском. Коммиты: `feat:`, `fix:`,
`refactor:`, `test:`, `docs:`, `chore:` и краткий диагноз. В PR опишите поведение,
проверки и ограничения. Новые платформенные обработчики должны сохранять
штатную обработку ввода. Не читайте текст UI и не записывайте события без согласия.

Проверяйте доступные платформы; недоступные отмечайте в ручном чеклисте.
Изменения схемы требуют совместимого сервера, тестов и обновления events.md.
Пакеты собираются CI; публикация требует тега версии и NUGET_API_KEY владельца.
