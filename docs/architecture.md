# Архитектура

## Поток данных

Платформенный наблюдатель ввода → чистый классификатор RTelemetry.Input →
ClickTracker → ITelemetryClient.Track → очередь → HTTP POST /v1/batches →
валидация/ключ/лимиты → IEventStore → Razor Pages/CSV.

Клиент и сервер не содержат игровых понятий. Смысловые события определяет адаптер
приложения; каталог TBG — пример в events.md.

## Клиент

`Track` добавляет событие в память под блокировкой. Согласие проверяется до
конвертации props и повторно при записи. Пока нет Granted, очередь не наполняется.
Отзыв отменяет текущую отправку и стирает память/диск; запрос, уже принятый сервером,
отменой удалить нельзя — для этого существует админ-удаление по installId.

Фоновый цикл сохраняет/отправляет очередь каждые 30 секунд и при заполнении батча.
Приложение без MAUI вызывает `Start()` и lifecycle API самостоятельно. Сохранение
остатка также выполняется при Dispose. При аварийном завершении возможно потерять
события после последнего сохранения. На диске атомарная замена через временный файл;
незавершённые временные и повреждённые файлы удаляются, а согласие сбрасывается в
Unknown при повреждении состояния. Не восстанавливаем временные файлы, чтобы не
воскресить очередь после отзыва согласия.

Лимиты: 20 000 событий в памяти и 16 МиБ JSON очереди на диске по умолчанию. При
переполнении сохраняются новейшие события. `Accepted` удаляет пачку; `Rejected`
(4xx кроме 429) удаляет с диагностикой; `RetryLater` сохраняет до повтора.
Экспоненциальная задержка с jitter 50–100% от текущего предела: от 2 секунд до
5 минут. Успех сбрасывает задержку. Удаление из очереди — по event Id, чтобы
ответ старой отправки не затронул новую очередь.

`OnForeground()` и `OnBackgroundAsync()` идемпотентны относительно состояния
переднего плана. При фоне пишется session.end и запускается Flush. Возврат ранее
SessionTimeout сохраняет sessionId и sequence; после 30 минут (настраивается)
создаёт новую сессию. Несколько коротких уходов дают несколько session.end одной
логической сессии; duration_ms накопительная от старта, включая короткий фон.
Диагностика — OnDiagnostic и опциональный ILogger; их исключения изолированы.

## Ввод MAUI

`UseRTelemetry` подключает lifecycle и наблюдателей автоматически. Android
делегирует Window.Callback исходному обработчику, Apple использует распознаватель
UIWindow без поглощения касаний, Windows — pointer events с handledEventsToo.
Наблюдатели передают только первый указатель; отменённое касание и drag не дают
события. Длинное неподвижное нажатие отмечается long_press.

Геометрия, hit testing, ближайший интерактивный элемент и пороги находятся в
RTelemetry.Input без зависимости от MAUI. MAUI строит снимок текущей верхней
страницы, включая модальную страницу и Toolkit Popup. Идентификаторы берутся
из AutomationId/StyleId/типа; содержимое Text/Placeholder не читается.
Ручной TrackClick остаётся для нестандартных источников: не вызывайте его повторно
для касания, которое уже захватывает автоматика.

Реальные устройства, перекрытия, Popup и пользовательский GraphicsView проверяются
по docs/development/manual-checks.md. Чистые unit-тесты не доказывают корректность
всех нативных иерархий.

## Сервер

Minimal API и Razor Pages живут в одном процессе. Схема 1 проверяется до записи;
идентификатор проекта ограничен безопасным алфавитом. Ключ клиента фильтрует мусор,
но не является секретом. Статистика/CSV защищены HTTP Basic; удаление — отдельным
админ-ключом. Production должен работать за HTTPS.

`RTelemetry:Storage:Provider` выбирает JsonLines (разработка) или Postgres.
PostgreSQL: EF Core + миграции при старте, полный конверт события в jsonb, уникальный Id,
`ON CONFLICT DO NOTHING` и индексы проекта/даты/версий/сессии/установки.
JSON Lines не дедуплицирует повторные доставки; файловый провайдер рассчитан на один процесс.
Очистка по receivedAtUtc сохраняет одинаковую семантику провайдеров.

Лимиты запросов независимы по IP и авторизованному проекту; очистка хранения
выполняется фоновой службой. Статистика ограничивает диапазон и объём результата,
чтобы оператор сузил фильтры вместо незаметного усечения CSV.
