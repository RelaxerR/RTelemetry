# События

> Каталог событий. Стандартные события понимает любой потребитель RTelemetry, профиль
> приложения описывает его собственные события. Любое изменение формата — по правилам
> `AI_MEMORY.md`, раздел «Инварианты».

## Конверт (схема 1)

Пачка (`TelemetryBatch`):

| Поле | Тип | Смысл |
|---|---|---|
| `schemaVersion` | int | Версия формата, сейчас `1` |
| `project` | string | Код проекта на сервере (`tbg`) |
| `installId` | GUID | Случайный идентификатор установки, создаётся клиентом |
| `platform` | string | `android 10.0 phone`, `ios 17.5 tablet` и т. п. |
| `events` | массив | До 500 событий |

Событие (`TelemetryEvent`):

| Поле | Тип | Смысл |
|---|---|---|
| `id` | GUID | Уникален; для дедупликации повторной отправки |
| `name` | string | `[a-z0-9._-]`, до 64 символов, первая буква или цифра |
| `timestampUtc` | ISO 8601 | Время по часам устройства |
| `sessionId` | GUID | Сессия |
| `sequence` | int64 | Номер в сессии с 1; порядок при равном времени |
| `appVersion` | string | Версия приложения (в MAUI — `версия+сборка`) |
| `contentVersion` | string? | Версия контента |
| `props` | объект? | До 32 свойств: строка ≤ 256, число, bool, null |

Сервер добавляет `receivedAtUtc` — время приёма. Расхождение с `timestampUtc` показывает
офлайн-отправку и неверные часы устройства.

## Стандартные события

| Событие | Когда | Свойства |
|---|---|---|
| `session.start` | Первый передний план с Granted или возврат после SessionTimeout | от приложения |
| `session.end` | Уход в фон / ручной EndSession | `duration_ms` + от приложения |
| `ui.click` | Завершённое касание/клик на интерактивном элементе | поля ниже |
| `ui.miss` | Завершённое касание фона, текста, картинки, пустого места или недоступной цели | поля ниже |
| `ui.screen` | Показ страницы (вызывает приложение) | `page` |

Короткий фон сохраняет sessionId и sequence. `session.end` может повторяться:
`duration_ms` — накопительное время от session.start, включая короткий фон,
а не длительность отдельного сегмента; не суммируйте эти значения.

### Определения ввода

`ui.click` — касание или клик мыши, завершённое на Button, ImageButton,
элементе с TapGestureRecognizer, CheckBox, Switch, RadioButton, Slider, Stepper,
Picker, DatePicker/TimePicker, Entry/Editor (фокус), выборе элемента
CollectionView/ListView, либо элементе с `RTelemetry.IsInteractive="True"`.
Событие фиксирует физическое взаимодействие, а не программное изменение значения.

`ui.miss` — касание, не попавшее в интерактивный элемент: пустое место, фон,
текст, картинка. Касание по отключённому (`IsEnabled=false`) или невидимому
элементу считается промахом с `disabled_target=true`, если его геометрия
доступна в снимке дерева. Удалённый из layout невидимый элемент может не иметь
геометрии; ограничения конкретной платформы проверяются вручную.

Одно физическое касание даёт одно событие; мультитач отслеживает первый палец.
Перетаскивание и прокрутка после превышения `DragThreshold` не дают события,
даже если указатель вернулся в исходную точку. Неподвижное нажатие дольше
`LongPressThreshold` даёт click/miss с `long_press=true`. По умолчанию пороги
12 логических единиц и 600 мс. Отменённые платформой жесты не записываются.

| Свойство | Тип | Значение |
|---|---|---|
| `element` | string | AutomationId → x:Name/StyleId → имя типа; при пустом промахе — страница |
| `element_type` | string | Имя типа элемента, при пустом промахе — тип страницы |
| `page` | string | Идентификатор текущей верхней страницы |
| `x`, `y` | number | Координаты отпускания относительно страницы, ограничены 0–1 |
| `long_press` | bool | Нажатие превысило настроенный порог времени |
| `disabled_target` | bool | Только miss: цель или её предок недоступны |
| `nearest_element` | string/null | Только miss: ближайший доступный интерактивный элемент |
| `nearest_distance` | number | Только miss: расстояние до границы элемента / диагональ страницы; 0 при отсутствии цели |

MAUI назначает StyleId из x:Name, когда StyleId не задан явно. Важным элементам
задавайте стабильный AutomationId. Ручной `TrackClick` оставлен для нестандартных
источников; он добавляет `kind` и не гарантирует координаты, если их не передали
явно. Не вызывайте его поверх автоматического касания — это создаст дубль.

Текст, Placeholder и введённое содержимое никогда не читаются трекером.
Собственные props приложения также не должны содержать такие данные.
`ui.miss` и новые плоские props расширяют каталог событий без изменения конверта:
клиенты и сервер продолжают использовать совместимую схему 1.

## Профиль The Book Game (`project = tbg`)

Адаптер реализован в [TheBookGame PR #522](https://github.com/RelaxerR/The_Book_Game/pull/522).
Сбор в игре пока закрыт до реализации согласия и проверки статуса связки.
Решения автора 20 октября 2026 года: [контракт исследования](study-contract.md).
Тексты реплик/вариантов не передаются; `line.shown` в пилоте отключён.
Эпизод — прохождение до `-End` (сейчас финал главы 3).

`contentVersion` — `tbg-` + первые 12 hex SHA256 экспорта; полный хэш и происхождение
в манифесте (раздел 5 контракта). Первая бета — `0.1.0`, `appVersion` —
`{version}+{build}.{commit7}` (локально `0.1.0+0.dev`).

| Событие | Когда | Свойства |
|---|---|---|
| `study.enrolled` | Успешная связка и согласие, один раз на вступление; ещё не реализовано | `consent_version`, `link=site`; без кода участника |
| `story.started` | Новая встроенная игра | `story_id=tbg`, `source=builtin` |
| `story.loaded` | Загрузка сохранения | `story_id`, `slot=auto/manual`, `scene_id` |
| `scene.shown` | Вход в сцену либо окончание восстановления сохранения | `scene_id` |
| `choice.shown` | Открытие окна с минимум двумя видимыми вариантами | `scene_id`, `choice_id`, `options` (число), `visible` (CSV исходных номеров) |
| `choice.made` | Принятый выбор, без повторного callback | `scene_id`, `choice_id`, `option_id`, `option_index`, `latency_ms` |
| `episode.completed` | Только `-End`, не обычный конец файла | `episode_id=end-<scene_id>`, `scene_id`, `duration_ms=null`, `choices_made=null` |
| `game.saved` | Успешное ручное/автосохранение | `slot=auto/manual` |
| `settings.changed` | Сохранённое изменение | `setting=sound_volume/music_volume/vibration`, `value` (0…100 или bool) |

Все смысловые события содержат `source=builtin`; custom/unknown исключены из адаптера.
Сцена обозначается `TextId`, поскольку `ContextId` меняется при сохранении.
`scene.shown` — вход движка, не подтверждение отрисовки кадра. При восстановлении
сохранения повторное исполнение старых команд не создаёт выборы и финал.
`choice_id=<scene_id>.c<N>` — номер группы соседних `-Choice` с 1 до фильтрации условий;
`option_index` тоже исходный номер с 1, `option_id` — целевая сцена.
Изменения порядка окон/вариантов анализируются с учётом contentVersion.
Единственный вариант проходит автоматически без события выбора.
`latency_ms` — монотонное время от открытия окна, включая фон, не активное время чтения.
Итоги финала null: полная история после загрузки/вступления посередине неизвестна;
методику их расчёта по выгрузке нужно определить отдельно.

При включённом SDK автоматически идут `ui.click`, `ui.miss` и `session.*`.
До подтверждённого статуса связки при запуске/возврате из фона запрещены сбор новых
событий и отправка очереди. В SDK есть отдельный допуск `SetCollectionEnabled`;
сохранённый `Granted` сам по себе не проверяет сайт. Проверка сайта — следующий этап игры.
Код участника, токен тестирования, лицензионные `sub`/`iid` и аккаунт сайта в события
не передаются. `installId` телеметрии независим от `iid` лицензии.
